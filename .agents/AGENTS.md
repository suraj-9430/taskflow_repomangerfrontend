# Project Rules & Customizations — TaskFlowPro

## Project Updates Generation Rule
- Whenever a new feature, major architectural update, backend API enhancement, or significant bugfix is implemented in TaskFlowPro:
  - **AUTOMATIC REQUIREMENT**: Always generate or update a descriptive Markdown document inside the `Project Updates/` directory (e.g. `Project Updates/<Feature_Name>.md`).
  - Document the overview, architectural components changed, API endpoints created/updated, frontend components added, and verification results.
